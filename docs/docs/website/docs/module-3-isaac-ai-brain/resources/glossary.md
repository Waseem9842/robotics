# Glossary: Isaac AI Robot Brain Concepts

This glossary defines key terms used throughout the Isaac AI Robot Brain module.

## A

**Application Binary Interface (ABI)**: Interface between user applications and the operating system in Isaac ROS components.

## I

**Isaac Sim**: NVIDIA's robotics simulation environment that provides photorealistic simulation capabilities for training AI systems.

**Isaac ROS**: Set of hardware-accelerated perception and navigation packages that run on ROS/ROS2.

**Isaac ROS Visual SLAM**: Visual Simultaneous Localization and Mapping package in the Isaac ROS suite that provides pose estimation using visual data.

## N

**Nav2**: Navigation Stack 2, ROS 2's navigation framework for path planning and obstacle avoidance.

**NVIDIA RTX**: Graphics processing unit architecture that provides the hardware acceleration for Isaac Sim and Isaac ROS.

## S

**Sensor Model**: Representation of sensor characteristics including noise, range, and accuracy in Isaac Sim.

**Synthetic Data**: Artificially generated training data from simulation that can be used to train AI models without real-world data collection.

## V

**VSLAM**: Visual Simultaneous Localization and Mapping, a technique that uses visual data for robot navigation and mapping.

**Virtual Sensor**: Simulated sensor in Isaac Sim that mimics the behavior of real-world sensors for testing and training.
