# Glossary

## VLA Terms

- **VLA (Vision-Language-Action)**: The integrated system combining speech recognition, vision processing, and LLM planning for robot control
- **Whisper**: OpenAI's speech recognition model used for voice command processing
- **Intent Mapping**: The process of converting transcribed speech to robot action intents
- **Task Decomposition**: Breaking down complex natural language tasks into sequences of robot actions
- **Action Sequence**: An ordered list of ROS 2 actions generated by the LLM planner
- **Simulation-First**: An approach that validates systems in simulation before real-world deployment

## Robotics Terms

- **ROS 2**: Robot Operating System version 2, the middleware for robot communication
- **Action**: A ROS 2 interface for long-running tasks with feedback
- **Navigation**: The process of moving the robot to a specified location
- **Manipulation**: The process of interacting with objects using a robot arm
- **Perception**: The process of understanding the environment through sensors
- **Sensing**: The process of detecting objects or conditions in the environment

## AI/ML Terms

- **LLM (Large Language Model)**: A neural network model designed to understand and generate human language
- **Prompt Engineering**: The technique of crafting inputs to guide LLM behavior
- **Fine-tuning**: The process of adapting a pre-trained model to a specific task
- **Confidence Score**: A measure of how certain the system is about its output
