# Capstone – Autonomous Humanoid

This chapter covers the complete end-to-end Vision-Language-Action (VLA) pipeline. We'll integrate all components to create an autonomous humanoid system with navigation, perception, and manipulation capabilities.

## Overview

The capstone chapter brings together all VLA components into a complete system. This involves:

- Combining speech, vision, and LLMs for robot control
- Implementing navigation, perception, and manipulation flows
- Validating the system using simulation-first approach

## Learning Objectives

By the end of this chapter, you will understand:

- How to integrate all VLA pipeline components
- Navigation, perception, and manipulation workflows
- Simulation-first validation for autonomous systems
