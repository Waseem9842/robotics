## Module Overview

This module teaches how to combine speech recognition, vision processing, and large language models to control humanoid robots through natural language commands. Students will learn to build complete VLA systems that can process voice commands, plan actions using LLMs, and execute them safely on robots.

## Learning Path

1. **Voice-to-Action**: Learn to integrate Whisper for voice processing
2. **LLM-Based Planning**: Use LLMs for task decomposition and planning
3. **Capstone**: Build complete end-to-end VLA pipeline with simulation-first validation
