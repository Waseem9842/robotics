# Navigation Flow

This section covers the navigation, perception, and manipulation flow in Vision-Language-Action (VLA) systems.

## Overview

The navigation flow integrates perception and manipulation capabilities to enable robots to navigate to targets, perceive their environment, and perform manipulation tasks based on voice commands and LLM planning.

## Technical Architecture

The navigation flow follows this architecture:

1. Voice command for navigation task
2. LLM planning for navigation route
3. Perception for environment understanding
4. Navigation execution
5. Manipulation if required
6. Feedback and confirmation

## Implementation Steps

### 1. Navigation Manager

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from geometry_msgs.msg import PoseStamped, Point
from nav_msgs.msg import Odometry
from sensor_msgs.msg import Image, LaserScan
import json

class NavigationManager(Node):

        super().__init__('navigation_manager')

        # Publishers
        self.goal_publisher = self.create_publisher(PoseStamped, 'goal_pose', 10)
        self.cmd_vel_publisher = self.create_publisher(String, 'cmd_vel', 10)
        self.navigation_result_publisher = self.create_publisher(String, 'navigation_results', 10)

        # Subscribers
        self.intent_subscriber = self.create_subscription(
            String,
            'robot_intents',
            self.intent_callback,
            10
        )

        self.odom_subscriber = self.create_subscription(
            Odometry,
            'odom',
            self.odom_callback,
            10
        )

        self.scan_subscriber = self.create_subscription(
            LaserScan,
            'scan',
            self.scan_callback,
            10
        )

        # Navigation state
        self.current_pose = None
        self.navigation_active = False

    def intent_callback(self, msg):
        """Handle navigation intents"""
        try:
            intent_data = json.loads(msg.data)
            intent_type = intent_data.get('type', '')

            if intent_type == 'navigation':
                target = intent_data.get('parameters', {}).get('target', '')
                self.get_logger().info(f'Received navigation intent to: {target}')

                # Convert target to coordinates
                target_pose = self.convert_target_to_pose(target)

                if target_pose:
                    self.navigate_to_pose(target_pose)
                else:
                    self.get_logger().error(f'Could not convert target "{target}" to coordinates')

        except json.JSONDecodeError as e:
            self.get_logger().error(f'Invalid JSON in intent: {e}')

    def convert_target_to_pose(self, target: str) -> PoseStamped:
        """
        Convert target name to coordinates

        """
        # Mock implementation - in real system, this would use a map

            'kitchen': (1.0, 2.0, 0.0),
            'living_room': (3.0, 1.0, 0.0),

            'office': (-2.0, 1.0, 0.0)
        }

        if target.lower() in target_locations:
            x, y, theta = target_locations[target.lower()]
            pose = PoseStamped()
            pose.header.frame_id = 'map'

        else:
            self.get_logger().warn(f'Unknown location: {target}')
            return None

        """Navigate to the specified pose"""
        self.get_logger().info(f'Navigating to pose: ({target_pose.pose.position.x}, {target_pose.pose.position.y})')

        # Publish the goal pose
        self.goal_publisher.publish(target_pose)

        # Set navigation active flag
        self.navigation_active = True

        # In a real implementation, this would:
        # - Send goal to navigation stack (Nav2)
        # - Monitor progress
        # - Handle navigation errors
        # - Report completion

    def odom_callback(self, msg: Odometry):
        """Update current robot pose"""
        self.current_pose = msg.pose.pose

    def scan_callback(self, msg: LaserScan):
        """Handle laser scan data for obstacle detection"""
        if self.navigation_active:
            # Check for obstacles in the path
            min_distance = min(msg.ranges)
            if min_distance < 0.5:  # Less than 0.5m to obstacle
                self.get_logger().warn('Obstacle detected, stopping navigation')
```

## Best Practices

- Use consistent coordinate frames across navigation, perception, and manipulation
- Implement proper state management for complex multi-step tasks
- Ensure safety checks are in place for all navigation and manipulation actions
- Provide feedback to users about the robot's progress
- Handle errors gracefully with appropriate fallback behaviors

## Troubleshooting

Common issues and solutions:

- **Coordinate frame mismatches**: Ensure all components use the same coordinate system
- **Navigation failures**: Implement obstacle avoidance and path replanning
- **Perception errors**: Use multiple sensors and robust detection algorithms
- **Manipulation failures**: Implement grasp verification and retry mechanisms
