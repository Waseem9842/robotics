# Voice-to-Action

This chapter covers the voice processing component of the Vision-Language-Action (VLA) pipeline. We'll explore how to use Whisper for voice commands and map speech to robot intents.

## Overview

The voice-to-action component enables natural language interaction with humanoid robots. This involves:

- Converting spoken commands to text using Whisper
- Mapping the transcribed text to robot intents
- Triggering appropriate ROS 2 actions

## Learning Objectives

By the end of this chapter, you will understand:

- How to integrate Whisper with ROS 2 for voice processing
- Techniques for mapping speech to robot intents
- How to trigger ROS 2 actions from voice commands
