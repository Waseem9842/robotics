# Glossary: Digital Twin Simulation Concepts

This glossary defines key terms used throughout the Digital Twin Simulation module.

## A

**Allan Variance**: A statistical measure used to characterize the noise properties of sensors, particularly IMUs, showing different noise types as a function of averaging time.

## D

**Digital Twin**: A virtual representation of a physical robot or environment that simulates real-world physics, sensors, and interactions.

**Domain Randomization**: A technique for training AI models on synthetic data with randomized visual and physical parameters to improve generalization to real-world data.

## G

**Gazebo**: A physics-based simulation environment that provides accurate simulation of gravity, collisions, and dynamics for robotics applications.

## I

**IMU (Inertial Measurement Unit)**: A sensor that measures linear acceleration and angular velocity, providing crucial information for robot localization and navigation.

## L

**LiDAR (Light Detection and Ranging)**: A sensing method that measures distances by illuminating targets with laser light and measuring the reflection.

## N

**Noise Model**: A mathematical representation of the random variations and errors present in sensor measurements.

## S

**Sensor Fusion**: The process of combining data from multiple sensors to create a more comprehensive and accurate perception of the environment.

**Simulation Pipeline**: The sequence of processing steps that transform raw sensor data into meaningful information for robot perception and control systems.

## U

**Unity**: A real-time 3D development platform used for creating visually rich environments for human-robot interaction and training applications.

## V

**Virtual Reality (VR)**: A computer-generated simulation of a three-dimensional environment that can be interacted with in a seemingly real way.

## Y

**YOLO (You Only Look Once)**: A real-time object detection system that divides the image into a grid and predicts bounding boxes and class probabilities directly.
